# Algorithms Specialization – OSSU Roadmap

This repository contains my learning journey through the [Algorithms Specialization](https://www.coursera.org/specializations/algorithms) from the Open Source Society University (OSSU) roadmap. It serves as a personal record of progress, notes, exercises, and study materials for the core algorithmic concepts covered throughout the specialization.

## Overview

The Algorithms Specialization is a four-part sequence focused on the foundations of algorithm design and analysis. The courses cover fundamental techniques such as divide and conquer, graph algorithms, greedy methods, dynamic programming, and complexity theory.

## Courses included

### 1. Divide and Conquer, Sorting and Searching, and Randomized Algorithms

This course introduces essential algorithmic paradigms and techniques for solving large problems efficiently. Topics include:

- Divide and conquer
- Sorting and searching
- Randomized algorithms
- Recurrence relations
- Performance analysis

### 2. Graph Search, Shortest Paths, and Data Structures

This part focuses on graph-based problem solving and the data structures that enable efficient traversal and optimization. Topics include:

- Graph search algorithms
- Breadth-first and depth-first search
- Shortest paths
- Heap and priority queue structures
- Graph data structures

### 3. Greedy Algorithms, Minimum Spanning Trees, and Dynamic Programming

This course explores optimization strategies and algorithmic thinking for selecting efficient solutions under constraints. Topics include:

- Greedy algorithms
- Minimum spanning trees
- Dynamic programming
- Optimal substructure
- Problem decomposition

### 4. Shortest Paths Revisited, NP-Complete Problems and What To Do About Them

This final course expands on advanced algorithmic reasoning and intractability. Topics include:

- Shortest path algorithms revisited
- Advanced graph optimization
- NP-complete problems
- Approximation and problem-solving strategies
- Computational complexity concepts
